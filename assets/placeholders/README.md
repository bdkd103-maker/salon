# Placeholder asset package

This folder is reserved for production-ready app assets that must be replaced before publishing.

Required files to add later:
- Android app icon set under `android/app/src/main/res/mipmap-*`
- Android adaptive icon foreground/background assets
- Android splash assets under `android/app/src/main/res/drawable*`
- iOS AppIcon assets under `ios/App/App/Assets.xcassets/AppIcon.appiconset`
- iOS Launch images under `ios/App/App/Assets.xcassets/Splash.imageset`
- optional Google Play store graphics

Use an approved visual identity only. Until a final branding package is provided, this folder can hold neutral placeholder graphics that match the current salon theme without pretending to be final brand media.
